# Unique Analytics Africa

Website for Unique Analytics Africa: data engineering, analytics, data science and AI engineering.

The whole site is the single file `index.html`. It has no build step and no outside dependencies, so it can be served by GitHub Pages as it is.

## Editing

- Text, links and colours are all inside `index.html`. Colours are the variables at the top of the `<style>` block.
- To swap the boardroom illustration for a real photo, add `assets/boardroom.jpg`.

## Hosting

Served with GitHub Pages from the `main` branch. The `CNAME` file holds the custom domain.
